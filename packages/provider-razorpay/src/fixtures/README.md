# Fixture provenance

All payloads are synthesized in `../generate.ts` from official documented samples,
with SDK type validation where accurate. They contain invented identifiers,
example.test addresses, non-ASCII notes and explicit synthetic-test markers.
No captures, customer data or credentials are included. INR, JPY and BHD amounts
exercise core's exponent table. These are shape tests, not claims about an
individual merchant account's enabled payment methods or currencies.
